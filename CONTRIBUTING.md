# Contributing to Navree

Thank you for helping. The guide for the framework itself (how to build it, test it and send a change) is [CONTRIBUTING.md in NavreeHQ/navree](https://github.com/NavreeHQ/navree/blob/main/CONTRIBUTING.md). The other repositories have a short guide of their own.

The short version:

1. For anything bigger than a typo, open an issue or a discussion first, so we can agree on the shape of the change before you write it.
2. Make one change per pull request, with a test that fails without it, and update the documentation in the same pull request.
3. Write commit messages as `type(scope): what the code now does`, for example `fix(http): reject a second Content-Length header`.
4. Be kind. The [Code of Conduct](CODE_OF_CONDUCT.md) applies in every Navree space.

Your contribution comes in under the same terms as the project: [MIT](https://github.com/NavreeHQ/navree/blob/main/LICENSE-MIT) or [Apache-2.0](https://github.com/NavreeHQ/navree/blob/main/LICENSE-APACHE), at the user's option (section 5 of the Apache License). There is no contributor agreement to sign.
