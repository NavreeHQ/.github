# Getting help

## Questions and ideas

Ask in [GitHub Discussions](https://github.com/NavreeHQ/navree/discussions). Search the discussions and the [documentation](https://navree.com/docs/prologue/introduction/) first; many answers are there. When you ask, say which Navree version you use (`navree --version`), your Rust version (`rustc --version`) and the features you turned on, and show the smallest code that has the problem.

## Bugs

Open an issue in the repository that holds the code:

| Repository | What it holds |
|---|---|
| [navree](https://github.com/NavreeHQ/navree) | the framework, the CLI, the documentation and the npm packages |
| [crm](https://github.com/NavreeHQ/crm) | the reference CRM built on Navree |
| [skeleton](https://github.com/NavreeHQ/skeleton) | the starting point for a new app |
| [benchmarks](https://github.com/NavreeHQ/benchmarks) | Navree's benchmark app and results |

Use the bug report form. A report with a reproduction gets fixed sooner.

## Security

Never report a vulnerability in a public issue. Email **security@navree.com**, or use "Report a vulnerability" in the Security tab of the repository. See [SECURITY.md](SECURITY.md) for what to expect.

## Conduct

To report a problem with someone's behaviour in our spaces, write to **conduct@navree.com**. See the [Code of Conduct](CODE_OF_CONDUCT.md).
