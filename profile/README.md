  The backend, the screens and the tools to run them, in one modular framework.<br>
  Auth, workspaces, an ORM, queues, search, real time and AI are already in the box.

## Start here

```sh
cargo install navree-cli
navree new agra --kit saas
```

## Repositories

| Repository | What it holds |
|---|---|
| [navree](https://github.com/NavreeHQ/navree) | The framework: its crates, the `navree` command, the documentation, the agent skills and the `@navree/*` npm packages |
| [crm](https://github.com/NavreeHQ/crm) | A complete CRM built on Navree: the API, and front ends in Next.js and Nuxt |
| [skeleton](https://github.com/NavreeHQ/skeleton) | The starting point of a new app, as `navree new` writes it. Use it as a template |
| [benchmarks](https://github.com/NavreeHQ/benchmarks) | Navree's benchmark app, harness and results |

Questions go to [Discussions](https://github.com/NavreeHQ/navree/discussions), bugs to the issues of the repository that holds the code, and security reports to security@navree.com.
