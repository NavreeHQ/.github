# NavreeHQ/.github

The community files that every repository in the [NavreeHQ](https://github.com/NavreeHQ) organisation gets by default. A repository that has a file of its own uses that one instead.

| File | What it is |
|---|---|
| `profile/README.md` | The text on the organisation's page |
| `CODE_OF_CONDUCT.md` | The Contributor Covenant, reports to conduct@navree.com |
| `CONTRIBUTING.md` | How to propose a change, with a pointer to the framework's guide |
| `SECURITY.md` | How to report a vulnerability |
| `SUPPORT.md` | Where to ask questions and report bugs |
| `ISSUE_TEMPLATE/` | The bug report and feature request forms, and the links on the "new issue" page |
| `PULL_REQUEST_TEMPLATE.md` | The pull request description |

GitHub cannot inherit `CODEOWNERS`, the licence files, workflows or `dependabot.yml`, so each repository keeps its own.
